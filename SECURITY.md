# Security

Please report a security problem privately through GitHub: open the Security tab of this repository and choose "Report a vulnerability". Do not open a public issue for it.

Include what you found, how to reproduce it and which version you ran. You will get a reply as soon as the report has been read.

Only the newest release receives fixes.

[The security guide](site/content/docs/security.md) describes how Cammut protects secrets, tokens and notes.
