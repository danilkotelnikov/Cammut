# Contributing

Open an issue first for a large change, so we can agree on the shape before you build it.

Keep each pull request small: one change, with its tests. Review tools read the whole diff, so a batch under 165 KB gets the best review.

Before you send it, run the checks listed in the README. The privacy scan must pass, and no secret, personal path or private address may enter the repository.

By sending a pull request, you agree that your change is under the same licence as the project, AGPL-3.0-only.
